# FinTrace 竞赛要求与验收口径

本文件将 `参赛要求编辑版.docx` 转为项目的唯一竞赛口径。任何答辩、白皮书、测试报告均以此为准；具体实现不在这里展开。

> 审查提示：本文件中的百分比和时延都是外部验收目标，不是当前实测结果。指标口径见 `09-Agent评测实施方案与结果模板.md`，冻结批次结果登记在 `08-统一评测清单与实施记录.md`；pytest 通过数和单次冒烟均不能作为替代。

## 目标

FinTrace 面向 A 股投研问答，以长上下文记忆、图谱推理和财务排雷为三条主线，输出可追溯证据支撑的回答与解释报告。

## 验收目标

| 方向 | 目标 |
| --- | --- |
| 长上下文与多轮问答 | 在 0.5M Token 累计历史压力下，关键事实召回与回答准确率均不低于 90%。 |
| 动态路由与纠错 | 工具调用 Precision 不低于 92%；可恢复错误恢复率不低于 80%。 |
| 图谱穿透 | 三层以上端到端路径准确率不低于 85%；图查询与结果组装不超过 5 秒。 |
| 事件脉络 | 关键事件节点 Recall 不低于 85%。 |
| 财务排雷 | 问题财报风险预警 F1 不低于 85%；专家盲评的逻辑自洽、数据引用无幻觉优秀率不低于 80%。 |

## 数据范围

赛题数据覆盖多轮问题、十大股东、违规公告、连续五年三表及附注/审计/问询文本、研报摘要，并含季度末复权收盘价、流通市值和行业等配套基础数据。数据是否可用于某项结论，仍取决于字段完整性、授权和金标定义。

## 交付物

- 长上下文记忆、图谱推理 Skill、财务排雷 Agent 的源代码与部署说明；
- 可交互的 Web 或 API 演示；
- 技术白皮书与答辩 PPT，明确防幻觉机制和跨科目勾稽设计；
- 可复现的评测集、运行配置、数据版本和结果报告。

## 口径约束

- 指标只可在冻结测试集上报告；规则命中率不能代替 F1，演示成功不能代替准确率。
- 证据不足时输出限制或拒答，不以模型常识补足事实。
- “动态图谱”“反欺诈”“0.5M”均是验收目标，必须通过对应数据、流程和评测证明。
