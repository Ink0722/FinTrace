# FinTrace 系统目标能力与数据边界

本文件定义目标能力，不描述某个版本是否已经实现。实现进度应由代码、测试和发布记录单独给出。

> 代码审查入口：能力是否开放以 `harness/routing/capability_registry.py` 为准，实际分发以 `tools/registry.py` 为准，参数与错误以 `tools/` 各工具目录下的 interface 模块为准。本文出现某个目标 operation 不代表其效果指标已达标。

## 目标能力

| 能力域 | 目标操作 | 可主张的结果 |
| --- | --- | --- |
| 文档证据 | `document_search.search` | 公告、财报文本和研报材料中的可定位文本证据。 |
| 财务分析 | `financial_analysis.metric_query`、`metric_compare`、`risk_scan` | 指标值、同口径比较、可复核的风险信号及规则链。 |
| 股权图谱 | `ownership_analysis.holding_query`、`holding_compare`、`penetration` | 时点股东快照、变动、可证实的有限路径及每跳证据。 |
| 事件脉络 | `event_timeline.event_query`、`event_cluster` | 有来源的事件筛选、排序和聚类。 |
| 研报观点 | `research_analysis.view_query` | 带机构、发布日期和原文定位的评级、预测、风险提示与分析判断。 |

## 不可越过的边界

- 十大股东快照不能证明完整股权结构、最终受益人或实际控制关系。
- 财务规则只能输出风险信号，不能将异常直接认定为造假。
- 研报材料应表述为机构观点，不可替代客观事实。
- 时间相邻的事件不能直接推导因果关系。
- 价格、行业和其他基础数据的使用必须带数据日期、来源与适用范围；不得将历史数据描述为实时行情。

## 统一证据要求

每一个关键事实应携带来源、时间、对象、原始定位和稳定 `evidence_id`。计算结果还应记录输入指标、口径、公式和数据版本。无法建立这些链路的结果不可作为强结论。

## 统一调用契约

所有工具调用使用统一 `ToolCall`：稳定调用 ID、工具名、操作、结构化参数、知识截止日与调用上下文；所有结果使用统一 `ToolResult`：状态、结构化数据、证据、警告和结构化错误。工具名描述能力域，`operation` 描述一次可验证职责；不得在一个调用中混合检索、计算、判断和自由文本解释。

通用参数包括公司/主体标识、报告期或日期范围、关键词/主题、文档/事件类型、返回上限和截止日。公司名称、证券代码与内部 ID 通过实体别名层解析；日期必须保留“披露日、事件日、报告期末、快照日”等语义，不能仅存一个无语义日期字段。

结果状态至少区分成功、空结果、数据不可得、输入校验失败、暂时失败与不支持。空结果不等于没有发生；样例回退不等于真实数据；可重试错误不等于可任意重复调用。

## 目标工具契约

### 文档、事件与研报观点

`document_search.search` 接收查询及公司、文档类型、日期、截止日等过滤，返回按相关性排序的 Chunk、来源元数据、定位和证据 ID。`event_timeline.event_query` 按主体、事件类型、关键词和时间范围筛选并排序；`event_cluster` 在保留原始事件的基础上返回可解释的聚合关系，不能删除来源事件。`research_analysis.view_query` 按公司、机构、观点类型、主题和日期查询离线观点；每条结果必须明确它是机构陈述而非独立核实的公司事实。

路由遵循“结构化结果优先、原文按需补充”：事件存在性、阶段和时序先用 `event_timeline`，机构评级、预测和风险看法先用 `research_analysis`；用户追问原因、金额、推理依据或完整上下文时，再调用 `document_search` 定位公告正文或研报摘要。直接要求原文或检索片段的问题可以直接进入 `document_search`。

### 财务与股权

`metric_query` 返回原始或已声明的派生指标及单位、报表口径、报告期和行级证据；`metric_compare` 只进行同口径、可确定的跨期或跨公司比较，并返回序列、差异和计算输入。`risk_scan` 只输出已声明规则的风险信号、阈值、公式和证据。

`holding_query` 返回某时点主要股东快照、持股比例、集中度及覆盖限制；`holding_compare` 返回两个有效快照间进入、退出、增持、减持和变动幅度；`penetration` 返回有限路径的每一跳方向、比例、时点、路径乘积和不完整警告。路径不存在只能说明给定数据中未发现，不能反证不存在控制关系。
