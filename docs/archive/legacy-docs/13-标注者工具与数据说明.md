# 标注者工具与数据说明

## 1. 文档用途

本文档面向参与问题标注的同学，帮助大家判断：

1. 一个问题需要依赖哪类数据；
2. 应该标注使用哪个工具；
3. 当前数据能回答到什么程度；
4. 哪些问题应标为数据不足或不可回答。

标注时只需要从金融问题理解和证据来源角度判断即可。

## 2. 标注总原则

1. 先判断问题是否落在现有五类数据范围内。现有数据之外的问题，不要强行标注为可回答。
2. 所有事实性回答都必须能在数据中找到依据。不能依赖常识、记忆或外部实时信息补充。
3. 多轮问题可以继承上文公司、日期和主题，但只有在当前问题明显延续同一话题时才继承。如果话题已经变化，不要强行沿用上一轮主体。
4. 财务异常只能标为“风险信号”，不能标为“已经造假”或“确认欺诈”。
5. 十大股东数据只代表“主要股东快照”，不能代表完整股权结构、完整基金持仓或最终受益人。
6. 研报摘要属于机构观点，不能直接当作客观事实。
7. 标注工具时选择最少且必要的工具。一个问题如果只需要查财务数字，就不要额外标注文档搜索或事件工具。

## 3. 数据集总览

| 数据集 | 主要内容 | 可以支持的问题 | 不能支持或需要注意 |
|---|---|---|---|
| 1. 多轮问题集 | 用户连续提问记录 | 用于评测 Agent 的多轮理解、工具选择和回答质量 | 它不是事实证据，不能作为答案来源 |
| 2. 十大股东快照 | 上市公司在不同日期的前十大股东及持股情况 | 主要股东、持股比例、股东变化、股东集中度、有限股权路径 | 不代表完整股东名单、实际控制人、最终受益人或完整基金持仓 |
| 3. 违规公告索引及正文 | 违规、监管、处罚等公告信息，部分公告有正文 | 监管事件、处罚事件、公告原文依据、事件时间线 | 没有正文时只能回答标题、日期、分类等信息 |
| 4. 三张财务报表 | 资产负债表、利润表、现金流量表 | 财务指标查询、跨期比较、公司比较、财务风险信号 | 不能直接证明财务造假，只能支持风险识别 |
| 5. 研报元数据和摘要 | 研报标题、机构、作者、发布日期、摘要等 | 机构观点、风险提示、研究关注点、摘要内容检索 | 当前不是完整研报全文，不能回答全文细节 |

## 4. 工具功能说明

### 4.1 `document_search`

这个工具用于查找文本证据，主要覆盖公告正文和研报摘要。

适合标注为 `document_search` 的问题包括：

1. 用户问“公告里怎么说”“原文依据是什么”“披露了什么”；
2. 用户问某家公司是否出现过监管公告、违规公告、处罚说明等具体文本内容；
3. 用户问研报摘要中提到的观点、风险提示或机构看法；
4. 用户要求给出证据片段、出处或文本依据。

不适合只用 `document_search` 的问题包括：

1. 精确财务数值查询，例如营收、净利润、现金流；
2. 财务指标计算，例如同比、增速、差额；
3. 股东持股比例或股东变化；
4. 需要实时行情或外部新闻的问题。

标注提醒：公告正文和研报摘要都属于文本证据。研报摘要是机构观点，不等于公司已经发生的客观事实。

### 4.2 `financial_analysis`

这个工具用于读取财务报表、计算财务指标、比较财务数据，并识别财务风险信号。

适合标注为 `financial_analysis` 的问题包括：

1. 查询某家公司某一报告期的营收、净利润、经营现金流、存货、应收账款等财务数据；
2. 比较同一家公司不同报告期的财务变化；
3. 比较不同公司在同一报告期的财务指标；
4. 分析收入、利润、现金流、存货、应收账款、负债等指标是否异常；
5. 识别财务风险信号，例如利润增长但经营现金流下降、存货增速明显高于收入增速等。

不适合标注为 `financial_analysis` 的问题包括：

1. 询问公告原文内容；
2. 询问股东名单和持股路径；
3. 询问机构研报观点；
4. 询问股价走势、技术指标、实时行情。

标注提醒：财务工具可以支持“风险预警”“异常信号”“值得关注”，但不能直接支持“公司造假已成立”这类结论。

### 4.3 `ownership_analysis`

这个工具用于分析十大股东快照，包括主要股东查询、股东变化比较和有限股权穿透。

适合标注为 `ownership_analysis` 的问题包括：

1. 查询某家公司某个时间点的前十大股东；
2. 查询某个股东是否出现在某些公司的主要股东名单中；
3. 比较某家公司两个时间点的主要股东变化；
4. 分析股东集中度或前几大股东持股占比；
5. 在数据支持时，查找某主体到某上市公司的有限持股路径。

不适合标注为 `ownership_analysis` 的问题包括：

1. 完整工商股权结构查询；
2. 实际控制人、最终受益人、一致行动关系的确认；
3. 完整基金持仓查询；
4. 未进入十大股东名单的普通小股东查询。

标注提醒：如果某主体没有出现在十大股东快照中，只能说明“当前数据未显示其为主要股东”，不能标注为“没有持股”。

### 4.4 `event_timeline`

这个工具用于查询、排序和聚合同一主体相关的事件，重点服务监管公告、违规事件和由结构化数据衍生出的重要变化。

适合标注为 `event_timeline` 的问题包括：

1. 查询某家公司发生过哪些监管、违规或处罚事件；
2. 要求按时间顺序整理某家公司事件脉络；
3. 询问某类事件在一段时间内如何发展；
4. 将多个相关公告或风险信号整理成事件簇；
5. 结合时间顺序观察股东变化、财务异常和公告事件之间的先后关系。

不适合标注为 `event_timeline` 的问题包括：

1. 单纯查询某个财务数字；
2. 单纯查询股东持股比例；
3. 单纯检索公告正文某一句话；
4. 推断未被数据证明的因果关系。

标注提醒：事件时间相近只能说明存在时间顺序或相关性，不能直接标注为因果关系。

## 5. 常见问题如何选工具

| 用户问题类型 | 建议工具 | 标注说明 |
|---|---|---|
| “某公司某年营收是多少？” | `financial_analysis` | 查询财务报表中的明确指标 |
| “某公司近几年利润变化如何？” | `financial_analysis` | 需要跨期比较财务指标 |
| “这家公司有没有财务风险？” | `financial_analysis` | 标注为风险扫描，不要标为确认造假 |
| “公告中具体披露了什么？” | `document_search` | 需要文本证据 |
| “某公司是否被处罚过？” | `event_timeline`，必要时加 `document_search` | 先查事件，再根据需要查公告正文 |
| “处罚事件的发展脉络是什么？” | `event_timeline` | 需要按时间整理事件 |
| “某公司的前十大股东是谁？” | `ownership_analysis` | 查询股东快照 |
| “某股东在两个时间点是否增持？” | `ownership_analysis` | 比较两期股东快照 |
| “A 是否通过多层主体持有 B？” | `ownership_analysis` | 只在数据能连成路径时可答 |
| “某研报怎么看这家公司？” | `document_search` | 研报摘要属于机构观点 |
| “现在股价涨跌如何？” | 不可回答 | 现有数据不含实时行情 |
| “我该不该买这只股票？” | 不可直接回答 | 可以提供风险和事实，不提供投资指令 |

## 6. 可回答性判断

标注时建议把问题分成三类：

| 类型 | 含义 | 示例 |
|---|---|---|
| 可回答 | 现有数据能直接支持问题所需事实或计算 | 查询某公司某期净利润、某日十大股东 |
| 部分可回答 | 现有数没有相关来源，但边界有限或者只是一般性问题 | 只能基于十大股东说明主要股东，不能证明完整控制链；对某个领域进行一般性的行研分析 |
| 不可回答 | 现有数据没有相关来源，或问题超出系统边界 | 实时股价、银行卡办理、完整基金持仓、外部最新新闻 |

如果问题是部分可回答，标注时应写明限制。例如：

1. “只能基于前十大股东快照判断”；
2. “当前只有研报摘要，没有全文”；
3. “当前公告正文缺失，只能使用公告标题和日期”；
4. “只能识别财务风险信号，不能确认财务造假”。

## 7. 五类数据与工具的对应关系

| 数据集 | 主要对应工具 | 辅助用途 |
|---|---|---|
| 多轮问题集 | 无直接工具 | 用于评测和人工标注 |
| 十大股东快照 | `ownership_analysis` | 可为 `event_timeline` 提供股东变化类事件 |
| 违规公告索引及正文 | `event_timeline`，`document_search` | 可为风险分析提供公告证据 |
| 三张财务报表 | `financial_analysis` | 可为 `event_timeline` 提供财务风险信号 |
| 研报元数据和摘要 | `document_search` | 可辅助解释财务变化或风险关注点 |

## 8. 标注时需要特别注意的边界

1. “最新”必须理解为用户提问时间点之前，数据集中已经披露的最新记录，而不是现实世界今天的最新情况。
2. “主要股东”可以由十大股东快照支持，“全部股东”不能由该数据支持。
3. “基金出现在十大股东中”可以回答，“基金完整持仓”不能回答。
4. “公告披露了某处罚”可以回答，“处罚背后的全部事实经过”不一定能回答。
5. “财务数据异常”可以回答，“确认财务造假”不能回答。
6. “研报认为”可以回答，“事实证明”不能从研报摘要推出。
7. “时间线中多个事件相邻”可以回答，“前一个事件导致后一个事件”不能直接推出。

## 9. 标注示例

### 示例 1

问题：`贵州茅台 2023 年净利润是多少？`

标注建议：

1. 可回答性：可回答；
2. 主要数据：三张财务报表；
3. 工具：`financial_analysis`；
4. 注意事项：需要明确报告期，答案应引用财务数据。

### 示例 2

问题：`这家公司有没有财务造假？`

标注建议：

1. 可回答性：部分可回答；
2. 主要数据：三张财务报表，必要时结合公告；
3. 工具：`financial_analysis`，必要时加 `document_search` 或 `event_timeline`；
4. 注意事项：只能回答风险信号，不能直接下“造假”结论。

### 示例 3

问题：`某基金现在持有哪些股票？`

标注建议：

1. 可回答性：部分可回答或不可回答；
2. 主要数据：十大股东快照；
3. 工具：`ownership_analysis`；
4. 注意事项：只能查询该基金是否出现在上市公司前十大股东中，不能回答完整基金持仓。

### 示例 4

问题：`某公司最近几年被处罚的时间线是什么？`

标注建议：

1. 可回答性：可回答或部分可回答；
2. 主要数据：违规公告索引及正文；
3. 工具：`event_timeline`，必要时加 `document_search`；
4. 注意事项：如果公告正文缺失，只能基于公告标题、日期和分类整理。

### 示例 5

问题：`某券商研报为什么看好这家公司？`

标注建议：

1. 可回答性：取决于研报摘要是否覆盖相关内容；
2. 主要数据：研报元数据和摘要；
3. 工具：`document_search`；
4. 注意事项：回答应表述为“研报摘要认为”，不能表述为客观事实。

## 10. 简明决策顺序

标注时可以按下面顺序判断：

1. 这是财务数字或财务风险问题吗？如果是，优先标 `financial_analysis`。
2. 这是股东、持股、穿透或股东变化问题吗？如果是，优先标 `ownership_analysis`。
3. 这是公告、监管、处罚、违规或事件脉络问题吗？如果是，优先标 `event_timeline`。
4. 这是要找原文、摘要、研报观点或文本依据吗？如果是，标 `document_search`。
5. 如果问题需要实时行情、完整外部信息、用户个人业务办理、投资买卖建议，则标为不可回答或只允许给出数据范围内的风险提示。

## 11. 给标注者的最后提醒

标注的核心不是猜 Agent 会怎么答，而是判断“一个严谨系统应该依据哪些数据回答”。如果数据不足，正确的标注不是逼系统回答，而是明确标出数据边界。这样后续评测才能区分两种能力：能答的问题是否答得准，不能答的问题是否能诚实拒答。
