# FinTrace 人工标注手册

标注目标是定义一个严谨系统**应依据哪些数据与证据**回答，而不是猜测某个模型会给出什么答案。

## 每轮标注字段

- 可回答性：`supported`、`partially_supported`、`clarification_needed`、`unsupported`、`unsafe_prediction`；
- 继承上下文：主体、时间、比较对象与主题；
- 目标能力与最少必要操作；
- 金标事实、证据定位和必要 Chunk；
- 限制说明与不可主张结论。

## 工具选择

| 问题 | 标注操作 |
| --- | --- |
| 原文、公告披露、研报观点 | `document_search.search` |
| 单期财务值 | `financial_analysis.metric_query` |
| 跨期或跨公司同口径比较 | `financial_analysis.metric_compare` |
| 明确风险规则 | `financial_analysis.risk_scan` |
| 主要股东快照或反向可见持股 | `ownership_analysis.holding_query` |
| 两个时点的股东变化 | `ownership_analysis.holding_compare` |
| 有来源的有限持股路径 | `ownership_analysis.penetration` |
| 事件筛选与时间排序 | `event_timeline.event_query` |
| 事件归并 | `event_timeline.event_cluster` |

## 强制边界

- 标注“完整控制链”“确认造假”“实时行情”前，必须有对应数据和证据；否则标为部分可回答或不可回答。
- 研报结论写作“研报认为”；股东数据写作“主要股东快照显示”。
- 多轮继承必须能从上文唯一确定，不能用猜测补全主体或日期。
- 标注的操作是目标口径；实际可执行操作以发布版本的能力清单为准。
