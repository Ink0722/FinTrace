# FinTrace 评测规范

## 正式指标

| 类别 | 指标 | 目标 |
| --- | --- | ---: |
| 完整 Agent | 回答准确率、关键事实 Recall、工具调用 Precision、自纠错成功率 | 90%、90%、92%、80% |
| 专项工具 | 股权路径端到端准确率、事件节点 Recall、工具延迟达标率 | 85%、85%、5 秒内 100% |
| 财务排雷 | 风险预警 F1、专家盲评优秀率 | 85%、80% |

## 评测流程

1. 定义测试单元、金标字段、允许证据和通过规则。
2. 冻结代码、Prompt、模型、工具、数据和索引版本。
3. 分别运行原始多轮集、长历史压力集、可恢复故障集和专项金标集。
4. 使用确定性规则优先判分；人工或 LLM 评审只处理预先定义的主观项。
5. 输出指标、置信区间（如适用）、失败案例与完整可复现元数据。

## 必要金标

- 0.5M Token 压力集：早期关键事实、干扰材料和正确证据位置；
- 深层股权路径集：实体、方向、比例、时点和每跳来源；
- 事件节点集：事件类型、日期、主体、文本来源和聚类归属；
- 问题财报集：公司、报告期、风险类型、正负标签和确认依据；
- 可恢复故障集：故障注入点、允许修复动作与成功判据。

过程诊断（成本、平均延迟、人工一致率等）不计入正式分数，但必须随报告保留。
